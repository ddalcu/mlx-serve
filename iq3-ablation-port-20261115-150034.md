## Decisions made (and why)
- Ablation is owned by the slot's `State`, not the call, so DSpark rounds that run directly on the module ablate too (Caps.ablation promises drafter rounds).
- Unkeyed ablations never continue rows (`fits` refuses) — two unkeyed directions are indistinguishable in the host's cache key.
- Tap seq comes from the target dir's `index.jsonl`, never memory; name claimed by exclusive create; index appended under an exclusive lock; a torn last record is cut back to the last newline (tensor stays, unindexed).
- Tests use a local tape-free rig rather than the shared proof harness: the shared one reaches `engines/mlx/plugin/tape.zig` and fails `scripts/unit_closure.py`.
- No two-full-iQ-server concurrency test: that phase preceded studio3 going offline, so cross-process lock contention is still unproven (filesystem-only harness owed).
