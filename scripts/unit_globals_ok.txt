# Globals a plugin unit (-Dunits) may hold its own copy of: scripts/unit_globals.py. `~` starts a pattern.
# A global the host sets or reads is never listed here: it is Shared (src/sdk/util/shared.zig).

# the standard library, the compiler, linker temporaries

~^(__anon|__unnamed|\.str|l_)

~^env\.|_env$|\.Env\.on$
