## Model loading, configs, converters, media parity (→ docs/gotchas/models-media.md)

- **A qwen4_exp checkpoint is NOT a qwen3_5 pack** (model_type `qwen4_exp`): three new blocks (hyper-connections, n-gram PLE, QSA) around the qwen3_5 trunk. The HF fixture's `hidden_states[i]` is the INPUT of layer i (stream_0 = tiled embeddings) — compare layer-i output with stream_{i+1}.
- **A random tiny MoE oracle ties everywhere, and the tie RATE is scale-invariant** (relu leaves EXACT-ZERO block scores; bf16 noise flips one top-k expert or QSA block per prompt): `dump_qwen4_exp_fixtures.py` runs every expert and dumps the reference's OWN margins; `Qwen4Ties` acquits under 3% by those, NEVER by our output.
- **A k < E tiny fixture ties in most trunk rows across every MoE layer, so its top-k SELECTION coverage is the MTP head's ONE MoE layer** (`dump_qwen4_exp_fixtures.py build --topk 2`; `route_gap`/`mtp_route_gap` = softmax margin at the top-k boundary, `QWEN4_TIE_REL_ROUTE` 5%). The k = E fixture stays the CI one.
- **qwen4_exp splices vision rows BEFORE the hyper-connection tile** (`forwardQwen4With`: `applyVisionEmbeddingsWith` on the `hidden`-wide embeddings, THEN `mlx_tile`). Tower + preprocessor + M-RoPE table are Qwen3-VL's (`config.qwen_vision`, shared with qwen3_5); the pack gets the tower via `--add-vision`. Guard: `qwen4 fixture vision`.
- **QSA's always-visible tail is PER QUERY** (tokens at/after `ratio·floor((p+1)/ratio)`), never `kv % ratio`; scores in f32 like the reference; `torch.topk` keeps the LOWER block index on exact-zero ties. The n-gram hash's eos is the TEXT config's (`ngram_eos`), not the generation stop set.
- **On qwen4_exp the spec "hidden" IS the pre-mixer stream** (`capture_hidden(_all)` = `[B,L,hc*hidden]`, never the mixed 2560): the MTP head fuses `fc_hidden(rms_{4H}(stream)) + fc_embedding(rms_H(embed))`. Head row r = (stream at r, token r+1) at query position r+1 — QSA takes a `pos_base` because its cache starts at position 1.
- **Per-request state outside conv/ssm rides `SSMCacheEntry.aux_state` + `ple_prev`** (PLE conv window, QSA raw-key history + its capacity buffers); every reset/free site goes through `ssmFreeQsaState`. `SSMCacheEntrySnapshot` carries them, so the prefix cache is ON. Restore-parity bar = the CHUNKING class (~0.3 nats top-5), not 0.047.
- **ACE-Step's timbre slot is the silence latent OR the reference clip's VAE mean, never both** (`MusicRequest.ref_audio`, #259): a conditioning SWAP, not a branch — `acestep.referenceWindow` makes every clip 30 s and `refTimbreLatents` encodes the MEAN. Guards assert the `[acestep] reference audio:` line, never output.
- **An ACE-Step TASK is the DiT's context stream plus the instruction line — same forward** (`MusicRequest.task`): `complete` (vocal2bgm) = source clip's raw VAE latent as `[src|ones]` + its line; `cover` = latent → pooler → FSQ (soft clamp `c·tanh(z/c)`, THEN the hard-clamp grid — neither alone) → detokenizer; source length IS track length. FSQ weights ship SEPARATE, DENSE bf16 (`fsq.safetensors`).
- **A standalone-frame latent belongs in latent slot 0 ONLY** (#260: elsewhere a 1-frame latent decodes as 8 frames of noise). First anchor REPLACES frame 0 (`VideoConditionByLatentIndex`); last anchor is APPENDED as `HW` clean tokens at pixel `num_frames-1` (`VideoConditionByKeyframeIndex`), trimmed before decode. `keyframeMask` + `keyframePositions` are the ONE place.
- **A capability the reference API exposes as a FLAG may reach the checkpoint only as TEXT** (`instrumental`, both music backends → `[Instrumental]` section tag). Flag + non-empty lyrics = NAMED 400 (`gen.instrumentalConflicts`; whitespace-only = absent). Guards assert `instrumental=true` IN THE LOG.
- **An adapter's alpha lives wherever its exporter put it** (`lora.fileAlphaScale`: nested-PEFT > flat > `ss_*` > none; per-module tensor WINS; non-finite DECLINED). A LoRA test comparing only BYTES can't tell adapter from noise — `tests/lora_noise.py` + `tests/test_real_loras.sh`.
- **A latent→RGB preview is a FIT per latent SPACE; the oracle proves fidelity to the REFERENCE, never resemblance to the video** (#208): `src/latent_rgb.zig` is GENERATED by `tests/dump_latent_rgb_factors.py` executing the reference (GPL spec, never transcribed). Live bar VAE-decodes a real latent and correlates against `goldenAngleControlMap`. `LTXAV` ≠ `LTXV`.
- **A condition stream is assembled in SEGMENT order by ONE resolver** (H3 `resolveRefs`; `refBlockFor` DERIVED). **Two partitions with IDENTICAL files need a DECLARED discriminator** (H3 `tasks` → `h3ConfigDeclaresRef2va`; server 400s, app gates the FIELDS).
- **A tiled decoder's tiles are not slices of an untiled pass when positions normalize over the EXTENT**: `fitsSingleTile` → `error.TilingUnsupported`; temporal chunking is semantic (17-frame clips).
- **A COSINE parity test cannot see a SCALE error**: anything CONCATENATED asserts `rms_ratio` too. A faithful port can make the checkpoint WORSE (H3 `<Picture i>` splice default-off fl2va). **An oracle that cannot execute the reference must say so.** **A permutation-invariant checksum cannot see a permutation** (`pos_weighted`).
- **A distilled FEW-STEP diffusion model can REQUIRE bf16** (MageFlow Turbo): RoPE rotates f32 then casts; timestep + freq table bf16-ROUNDED (`roundBf16`); `scalarLike`. Debug the LOOP per-step in the native dtype.
- **A reference-image editor must not change its input's geometry**: `resolveEditTargetSize` = `fitAspect` → `fitWithinCap`; `encodeEdit` asserts pad count == merged vision rows.
- **A gather-read table may be quantized only where the READER has a quantized-gather path**: media backends read with dense `mlx_take_axis` → `NEVER_QUANTIZE` lists; LM `embed_tokens` via `gatherQuantizedRows` is a SIZE decision (measured within ±2se; our packs quantize it, `tests/restandardize_qwen38_pack.py`).
- **Publish MTP head norms FOLDED** (`--fold-mtp-norms`): same bytes at serve time as delta + load-fold; drops reliance on detection heuristics. A pack whose BACKBONE norms move the anchor (Alis) is what breaks oMLX, not the convention.
- **A chain that returns f32 BY DESIGN makes the CALLER own the activation dtype** (`groupLimitedRouting`): forgetting promotes the residual at the first MoE layer — ONE `[dtype-trace] residual widened` line is the symptom.
- **Calibrated quantization**: channel weights PER-INPUT-CHANNEL and PER-EXPERT (imatrix value IS the weight); bit width beats group granularity ≤3 bits; round (s,b) to the STORED dtype before q; self-test against a weight-BLIND arm.
- **A sampler never draws a RESERVED special OR a PADDING row; the legit set is DERIVED** (`tokenizer.reservedOutputIds` + `definedVocabSize` → `installSuppressMask`, `MLX_SERVE_SUPPRESS_RESERVED=0`): `[defined, logits_dim)` decodes to nothing and is masked, unless the checkpoint declares `unpadded_vocab_size` (ONE trim, never both). Logprobs stay RAW.
- **A hand-rolled pretokenizer is calibrated to ONE tokenizer.json — digit GROUPING is per-model** (`Tokenizer.digit_group`); mis-grouping presents as a QUALITY bug; cross-check `/tokenize` vs HF at bring-up. **A COMBINED Split regex hides the digit rule** (Llama-3 → `pretok_style = .llama3`).
- **The degenerate-tail loop guard needs a LONG-period tier**: periods 9..64 at 10 reps (`isDegenerateTailLoopRange`).
- **An imatrix is only valid for the WEIGHTS it was collected on**; byte-identical shard reuse is enforced by COPYING. **Uniform ≤2-bit experts to the LAST layer cause TURN-LEVEL agent loops** — low-bit gates need an AGENT-LOOP cell; 4-bit tail experts fix it.
- **A configless repo SHAPE must be taught to every "is this a model?" answer**: ONE predicate (`model_discovery.peekMageFlowIndex`; klein keyed on a WEIGHT NAME); `gen.peekModelType` DELEGATES.
- **A directory filter that skips `.sym_link` measures an HF-cache model at ZERO**: every size sum stats THROUGH symlinks (`statFile` follows, post-stat `.file` check). Sites: `scheduler.modelDiskBytes`, discovery, `gen.sumSafetensorsIn`, cli.
- **An incomplete media pack is invisible until its marker lands** (`model_discovery.requiredMediaMarker`, `gen.requiredMarkerFor` delegates): discovery skips, `probeModelDir` refuses `error.IncompleteMediaPack`, preload refuses by name. Guards: `tests/test_model_rescan.sh`, `TurboLoraFetchTargetTests`.
- **A family's geometry comes from the CHECKPOINT once a second size exists** (FLUX.2 klein 4B/9B): derive from SHAPES; TE heads from `q_proj` ROWS; fused gate+up = rows÷2.
- **An engine that hardcodes its pack's quant WIDTH can only load that pack** (ltx `bits=4` literal killed the 8-bit pack): every site solves via `affineParamsFromGeometry` (`quantGeom`). Scan-pinned: no literal width at any `mlx_quantized_matmul`/`mlx_dequantize` site.
- **4-bit affine on a video DiT is a QUALITY setting** (LTX-2.5: ~9.9% noise/linear vs 0.6% at 8-bit, 3.5% time cost). Mirror `ddalcu/LTX-2.5-MLX-Serve-8bit`; `scripts/quantize_ltx25.py --bits 8`.
- **A module's constructor arguments are not its config** (LTX DiffVAE: class defaults run the weights into STATIC; measured 1-step x0 at t×1000). `ltx_diffvae_forward.Sampler` pins all three behind kill switches; faithful-port parity CANNOT see this.
- **The DiffVAE's tile budget is a per-REQUEST memory decision** (`tileTokensForMemory` from free RAM at decode; stages 1-3 full volume, stage 4 + diffusion tile with trapezoid ramps summing to 1). Not a load-gate term.
- **A canvas the model was never asked to fill cannot be sharpened by steps/guidance/quant**: `VideoModelPreset.recommendedResolution(totalGB:)` sizes per Mac, capped by `autoCanvasCapPixels` (TIME budget); two-stage denoises at HALF (`twoStageCanvasNote`); frame ladder per canvas; `maxFramePayloadBytes` is a TRANSPORT limit.
- **A media pack's RELEASE is a config field, and the text encoder is what it decides** (`LtxVersion` from `model_version`, absent ⇒ 2.3): 2.3 borrows `mlx-community/gemma-3-12b-it-4bit`, 2.5 ships `gemma4-12b-ltx-v1/` in-pack (`MediaBundle.ltx25TextEncoderDir`). A mismatch renders a plausible video for the wrong prompt.
- **The 2.5 text encoder runs the REAL gemma4 transformer** (`ltx_video.gemmaCapture4` via `capture_layers` + `skip_lm_head`); left-padded prompts ride `ForwardCtx.prefill_mask_add` (already causal, FINITE -1e9, declines both fused prefill kernels; null on serving paths).
- **`keyframes_abs_pos_embedding` marks GENERATED keyframe slots, never given-content tokens** (reference `extend_keyframes_mask(marked=False)` for image guidance; the 2.5 checkpoint's row is ~0 anyway). We build no generated slots, so the parameter is parsed and never added.
- **A bytes-read table prices a lever only for a path already AT its read floor** (music3 depth KV: estimated 1–3 ms, measured −11.6). Per-stage probe laps (`MUSIC3_COST_PROBE`) before bandwidth arithmetic.
- **Music3 is NOT an ACE-Step variant**: timestep is a prepended TOKEN (no AdaLN), SwiGLU REVERSED (`first * silu(second)`), Snake alpha-only no exp, DiT RoPE dims-32 theta-10000 hardcoded, AR frame 0 never emitted but feeds back. Full list: the music3 story.
- **When an arch's reference IGNORES a config field, that field is not the truth** (laguna YaRN mscale COMPUTED). **A config field HF allows in two SHAPES must be read as both** (`chat_template` string OR list); `.string` on unchecked `std.json.Value` panics. **Read `text_config` FIRST, then root, PER FIELD.**
- **`x-mlx-pixels` is a GEMMA format; the client gate is an allowlist of ONE** (`wantsServerPreprocess` = `!hasPrefix("gemma")`); server `parseImageUrlContent` refuses when `vp.mode != .gemma`; `VisionEncoder.forward` returns named errors, never dereferences sentinels.
- **The text-model loader's `--no-vision` drop list is a GLOBAL prefix filter, so a media backend that shares a key spelling with an LM tower loses its weights** (MageFlow Edit's `model.visual.*` vanished the day the Alis-pack rename joined the list; every Edit load 503'd `MissingMageFlowWeight` for weeks). A tower loads through `loadWeightsWithVision`, never `loadWeights`. Guard: `VisionTower.openWeights` test in `mage_flow.zig`.
- **A placeholder id the splice mask does not name is a modality that never reaches the prompt** (`spliceVisionRows` keyed on image | audio ids; Qwen VIDEO pads were inserted, encoded and never scattered). Mask + `countSpliceRows` take `video_token_id`; an e2e vision bar must name something only the pixels could supply.
- **A chunked vision splice resumes its ROW INDEX** (#197, `vision_splice_offset`); repro needs prompt > chunk+512 (`TAIL_MERGE_MAX`); bar = PERCEIVED-content invariant, never bytes. Guard: `tests/test_vision_chunked_prefill.sh`.
- **A forward ARM that never splices vision is invisible from the outside** (LFM2-VL hybrid arm answered "a black rectangle"). Class guard: source scan `every generative forward arm splices vision embeddings`, encoder-only arms exempt BY NAME.
- **A resampled position table is `bilinear` WITH antialias** (SigLIP2-NaFlex; mlx-vlm's bicubic is a 1.13x rms scale error, not an oracle): `qwen_vision.resampleWeightMatrix(.bilinear)`.
- **Patch feature order is per-ARCH** (LFM2-VL channel INNERMOST; Qwen/Muse outermost). **Two GELUs in one checkpoint** (LFM2-VL encoder tanh, projector erf). **For NaFlex, TILING is the resolution** (canvas resampled ONCE, read as windows). Guards: `tests/test_lfm2_vision.sh`.
- **A checkpoint's processor pixel bound is not the ENGINE's** (`qwen_vision.effectivePixelBounds`, `ENGINE_MAX_PIXELS` 1536²): our tower MATERIALIZES the score matrix; a 5100x3300 photo OOM'd. Logs once.
- **A tower's PREFIX and `patch_embed.proj` AXIS ORDER are converter choices — probe** (`resolveVisionPrefix` + `patchProjLayout`; channels-last vs channels-first reads as a striped-pattern tower). Probe colours in THREE.
- **Two towers on one surface means the PREPROCESSOR is part of the arch** (muse: aspect-closest grid under MERGED cap, Lanczos, row-major, CHANNEL-major shuffle). `VisionPreproc.mode` picks all of it. Guards: `tests/dump_muse_vision_fixture.py`, `tests/test_muse_vision.sh`.
- **A config default only ONE family wants is a per-arch trap — pin every value PER LAYER TYPE** (muse sliding layers read `rope_local_base_freq` default 10000 vs its 500000 → first-turn loops). Guard: `tests/test_muse_repetition.sh`.
- **A module TREE is the converter's choice** (`lagunaRouterBase`: flat `mlp.gate.weight` vs nested `.proj.`; probe, flat preferred — the `hy3ExpertContainer` pattern). **WEIGHT PREFIX is a property of the checkpoint** (`model.resolveWeightPrefix` probes).
- **A layer-init path that DEMANDS `.scales` can't load a DENSE checkpoint**: scales absence PER-TENSOR (`getLayerScaleOpt`); every dense contracted weight owes `maybeTransposeForBf16` — never depthwise conv or SSM state. Source scan rejects the mandatory getter.
- **`*_text` siblings**: accept the tag, collapse to base type, prefix by `text_config` presence, force `tie_word_embeddings` for Gemma, add to BOTH visibility allowlists. **Gemma terminators merge ADDITIVELY** (`ensureGemmaTerminators`).
- **Quant modes resolve PER WEIGHT** (`computeQuantParams`; scales dtype decides fp8 vs affine; `.biases` mandatory under affine). **A per-tensor override can hide INSIDE the fp family** (`fpParamsFromGeometry` solves from packed geometry). **Affine bits outside {2,3,4,5,6,8} rejected at PARSE** (`UnsupportedQuantBits`).
- **A GGUF folder is a SHELF of models**: one `LocalModel` per quant (`id#<file>`), sidecar classifiers in sync in Swift AND Zig.
- **DiffusionGemma parity = converged-canvas self-consistency** (`MLX_SERVE_DIFFUSION_TRACE=1`); sliding prefill takes `"causal"` when `total_kv ≤ sw`. **Optional per-token modulation gates on the mask** (`nv_pt==0` → exact scalar path).
- **Parity fixtures for deep ViTs/DiTs: dump fp32 on CPU** (MPS fp16 decorrelates); transformers ≥5 zeroes custom rotary buffers — dump scripts assert non-zero; an oracle that IMPROVES when you remove a transform had it silently disabled.
- **TTS**: `TimeDelayNetBlock` = conv + IMPLICIT ReLU; embedding lookups reshape to the TABLE's width (`getShape`); voice clone = ECAPA embedding as one codec-prefix position, `ref_text` ignored.
- **A pinned library's op TRANSIENT is invisible to every residency bill** (#321): MLX ≥ 0.32.2 splits a temporal-pad-0 N=1 3D conv into per-tap 2D convs under a whole-GPU Winograd budget; LTX VAE decode OOM'd. `conv3dDepthChunked` windows decoder convs (exact). Diff conv DISPATCH per mlx bump.
